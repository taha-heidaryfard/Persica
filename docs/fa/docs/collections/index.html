آرایه‌های تایپ‌شده

آرایه‌ها در پرسیکا از اندیس صفر شروع می‌شوند، به طور پویا رشد می‌کنند و دارای نوع مشخصی برای تضمین همگنی عناصر هستند:

arrays.persi
// آرایه‌ای از اعداد صحیح
int[] numbers = [10, 20, 30, 40];
// دسترسی و تغییر مقدار با اندیس
print(class="token-str">"First element:", numbers[0]);
numbers[1] = 99; // تغییر مقدار خانه دوم
// اندیس منفی برای دسترسی از انتهای آرایه
print(class="token-str">"Last element via -1:", numbers[-1]);
print(class="token-str">"Updated array:", numbers);
Output:
First element: 10
Last element via -1: 40
Updated array: [10, 99, 30, 40]

آرایه‌های چندبعدی و ماتریس

آرایه‌های تو در تو به راحتی با تکرار جفت کروشه‌ها (مانند int[][]) تعریف می‌شوند:

matrix.persi
int[][] matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
];
print(class="token-str">"Center element [1][1]:", matrix[1][1]);
matrix[0][2] = 99;
print(class="token-str">"Row 0 updated:", matrix[0]);
Output:
Center element [1][1]: 5
Row 0 updated: [1, 2, 99]

توابع کمکی آرایه

تابعخروجیتوضیحات
len(arr)intتعداد عناصر آرایه را برمی‌گرداند.
append(arr, item)voidعنصر جدید را به انتهای آرایه اضافه می‌کند.
sort(arr)arrayیک کپی مرتب‌شده به صورت صعودی برمی‌گرداند.
reverse(arr)arrayیک کپی معکوس از آرایه برمی‌گرداند.
slice(arr, start, end)arrayبرش زیرمجموعه از آرایه با پشتیبانی از اندیس‌های منفی.
sum(arr)int | floatمجموع تمامی عناصر عددی آرایه.
helpers_demo.persi
int[] data = [42, 10, 88, 3, 27];
print(class="token-str">"Original:", data);
print(class="token-str">"Sorted copy:", sort(data));
print(class="token-str">"Reversed copy:", reverse(data));
print(class="token-str">"Sum of elements:", sum(data));
print(class="token-str">"Slice [1:4]:", slice(data, 1, 4));
Output:
Original: [42, 10, 88, 3, 27]
Sorted copy: [3, 10, 27, 42, 88]
Reversed copy: [27, 3, 88, 10, 42]
Sum of elements: 170
Slice [1:4]: [10, 88, 3]

دیکشنری‌های داینامیک (`dict`)

برای داده‌های ساختاریافته کلید-مقدار شبیه JSON که مقادیر می‌توانند از انواع گوناگون باشند، از dict استفاده می‌شود:

dictionaries.persi
dict user = {
    class="token-str">"id": 101,
    class="token-str">"name": class="token-str">"محمد طاها",
    class="token-str">"verified": true,
    class="token-str">"rating": 4.9
};
print(class="token-str">"User Name:", user[class="token-str">"name"]);
user[class="token-str">"role"] = class="token-str">"Admin";
print(class="token-str">"User updated:", user);
Output:
User Name: محمد طاها
User updated: {"id": 101, "name": "محمد طاها", "verified": true, "rating": 4.9, "role": "Admin"}

مپ‌های تایپ‌شده (map<K, V>)

زمانی که می‌خواهید نوع کلید و مقدار به شکل ایستا در زمان کامپایل بررسی شود، از ساختار map<KeyType, ValueType> بهره ببرید:

typed_map.persi
map<string, int> scores = {
    class="token-str">"Alice": 95,
    class="token-str">"Bob": 88
};
scores[class="token-str">"Charlie"] = 92;
print(class="token-str">"Alice's score:", scores[class="token-str">"Alice"]);
Output:
Alice's score: 95
