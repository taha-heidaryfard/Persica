شروط و ساختارهای کنترلی

راهنمای کامل شاخه‌بندی شرطی if/else، حلقه‌های پایتونی for-in، تابع مولد range، حلقه‌های while و دستورات break و continue.

شروط `if` و `else`

در پرسیکا، گذاشتن پرانتز دور شرط‌ها اختیاری است. می‌توانید ساختار تمیز و خوانای پایتونی یا فرم پرانتزدار متداول در زبان‌های C را به کار ببرید:

conditions.persi
int score = 88;
if score >= 90 {
    print(class="token-str">"Grade: A");
} else if score >= 80 {
    print(class="token-str">"Grade: B");
} else if score >= 70 {
    print(class="token-str">"Grade: C");
} else {
    print(class="token-str">"Grade: F");
}
Output:
Grade: B

حلقه‌های پایتونی `for ... in`

پرسیکا پیمایش مستقیم و صریح روی آرایه‌ها و رشته‌ها را با ساختار for item in collection فراهم می‌کند:

for_in.persi
// پیمایش مستقیم عناصر یک آرایه
string[] fruits = [class="token-str">"Apple", class="token-str">"Orange", class="token-str">"Pomegranate"];
for fruit in fruits {
    print(class="token-str">"Fruit:", fruit);
}
// پیمایش کاراکتر به کاراکتر رشته یونیکد UTF-8
string greeting = class="token-str">"سلام";
for char in greeting {
    print(class="token-str">"Char:", char);
}
Output:
Fruit: Apple
Fruit: Orange
Fruit: Pomegranate
Char: س
Char: ل
Char: ا
Char: م

تابع مولد `range()`

تابع توکار range() دنباله‌ای از اعداد صحیح را تولید می‌کند و می‌تواند ۱، ۲ یا ۳ آرگومان دریافت نماید:

نحوه فراخوانیمقادیر تولیدیتوضیحات
range(5)[0, 1, 2, 3, 4]از صفر تا قبل از مقدار پایانی (نامشمول).
range(1, 6)[1, 2, 3, 4, 5]از مقدار آغازین تا قبل از پایان.
range(0, 10, 2)[0, 2, 4, 6, 8]با گام حرکت سفارشی (Step).
range(5, 0, -1)[5, 4, 3, 2, 1]شمارش معکوس با گام منفی.
range_demo.persi
// شمارش معکوس با گام منفی ۱
print(class="token-str">"Countdown starting:");
for i in range(3, 0, -1) {
    print(i, end=class="token-str">"... ");
}
print(class="token-str">"Liftoff! 🚀");
Output:
Countdown starting:
3... 2... 1... Liftoff! 🚀

حلقه‌های `while`

تا زمانی که شرط منطقی حلقه برقرار باشد، بدنه حلقه مرتباً تکرار می‌شود:

while_demo.persi
int n = 1;
while n < 32 {
    print(class="token-str">"Power of two:", n);
    n *= 2;
}
Output:
Power of two: 1
Power of two: 2
Power of two: 4
Power of two: 8
Power of two: 16

حلقه‌های سبک سی (C-Style Indexed `for`)

برای تکرارهای سنتی دارای متغیر شمارنده، شرط توقف و گام افزایش صریح:

c_style.persi
for (int i = 0; i < 3; i++) {
    print(class="token-str">"Index:", i);
}
Output:
Index: 0
Index: 1
Index: 2

دستورات `break` و `continue`

با break می‌توان بلافاصله از حلقه خارج شد و با continue تکرار فعلی متوقف و گام بعدی آغاز می‌گردد:

jump.persi
for i in range(1, 10) {
    if i % 2 == 0 {
        continue; // رد کردن اعداد زوج
    }
    if i > 7 {
        break; // پایان حلقه در صورت بزرگتر شدن از ۷
    }
    print(class="token-str">"Odd:", i);
}
Output:
Odd: 1
Odd: 3
Odd: 5
Odd: 7
