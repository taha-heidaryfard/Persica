کدنویسی لذت‌بخش و سینتکس دلنشین

برنامه‌ها را به سادگی یک اسکریپت اجرا کنید، یا پروژه‌های بزرگ شیء‌گرا بسازید.

hello.persi
// بدون نیاز به تابع main یا تعریف کلاس: مثل پایتون مستقیم اجرا کنید!
print(class="token-str">"درود بر برنامه‌نویسان پرسیکا! 🌿");
int sum = 0;
for num in range(1, 6) {
    sum += num;
    print(class="token-str">"گام:", num, class="token-str">"مجموع انباشته:", sum);
}
print(class="token-str">"مجموع نهایی:", sum);
Output:
درود بر برنامه‌نویسان پرسیکا! 🌿
