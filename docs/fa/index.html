راهنمای جامع زبان برنامه‌نویسی پرسیکا (Persica) 🌿

پرسیکا یک زبان برنامه‌نویسی مدرن، ایستا-نوع (Statically-Typed) و کاملاً مستقل است که از صفر تا صد با زبان Rust پیاده‌سازی شده است. این زبان زیبایی و سادگی سینتکس پایتون را با ایمنی و قابلیت اطمینان سیستم‌های تایپ‌شده ترکیب کرده است.

فهرست موضوعات راهنما:

  • ۱. نصب نصاب ویندوز و کامپایل سورس
  • ۲. اجرای بدون تشریفات فایل تکی
  • ۳. سیستم پروژه persica.toml و محیط .persi_env
  • ۴. انواع داده‌ها، متغیرها و final
  • ۵. مدل شیء‌گرایی: struct و class
  • ۶. مدیریت خطا و استثناها (try / catch / throw)
  • ۷. کتابخانه استاندارد خودمیزبان و Prelude
  • ۸. افزونه رسمی وی‌اس‌کد (VS Code Extension)
  • ۹. حمایت مالی از پروژه (رِیمیت)

۱. نصب و راه‌اندازی (Windows)

ساده‌ترین راهکار، دانلود فایل نصاب خودکار رسمی است که مسیر کامپایلر را خودکار در PATH ویندوز اضافه می‌کند و پسوند فایل‌های .persi را در سیستم رجیستر می‌نماید:

دانلود نصاب رسمی ویندوز (Persica-0.13.0-Windows-x64-Setup.exe)

تست نسخه در ترمینال:

Terminal
persica --version
Output:

۲. اجرای بدون تشریفات فایل تکی (Zero-Ceremony)

برای نوشتن اسکریپت‌های سبک یا تست قطعه کد، نیازی به تعریف کلاس یا ساختار پروژه ندارید. یک فایل به نام test.persi بسازید:

test.persi
// چاپ پیام و اجرای یک حلقه ساده
print(class="token-str">"درود بر برنامه‌نویسان پرسیکا! 🌿");
int sum = 0;
for i in range(1, 6) {
    sum += i;
    print(class="token-str">"گام:", i, class="token-str">"مجموع فعلی:", sum);
}
Output:
درود بر برنامه‌نویسان پرسیکا! 🌿
گام: 1 مجموع فعلی: 1
گام: 2 مجموع فعلی: 3
گام: 3 مجموع فعلی: 6
گام: 4 مجموع فعلی: 10
گام: 5 مجموع فعلی: 15

۳. سیستم پروژه persica.toml و محیط ایزوله .persi_env

برای پروژه‌های چندفایله بزرگ، دستور persica new ساختار کامل پروژه را می‌سازد:

Terminal
persica new my_app
cd my_app
persica run

محتوای فایل persica.toml:

persica.toml
[package]
name = "my_app"
version = "0.1.0"
entry = "src/main.persi"
source = "src"

[environment]
env_dir = ".persi_env"

محیط .persi_env پکیج‌های شما را به صورت ایزوله نگهداری می‌کند بدون آن که فایل‌های اجرایی سنگین و تکراری مفسر کپی شوند.

۵. شیء‌گرایی: struct و class

پرسیکا تمایز دقیقی میان ساختار داده‌ای مقداری خالص (struct) و اشیاء ارجاعی دارای متد و رفتار (class) قائل است:

oop.persi
// مدل داده‌ای خالص (Value Semantics)
struct Point {
    int x;
    int y;
}
// شیء دارای متد و رفتار (Reference Semantics)
class Wallet {
    string owner;
    int balance = 0;
    void add_funds(int amount) {
        this.balance += amount;
    }
    int get_balance() {
        return this.balance;
    }
}
Wallet w = Wallet();
w.owner = class="token-str">"محمد طاها";
w.add_funds(2500);
print(class="token-str">"موجودی کیف پول:", w.get_balance());
Output:
موجودی کیف پول: 2500

۶. مهار خطا و استثناها (try / catch / throw)

تمامی خطاهای درونی رانتایم (تقسیم بر صفر، اندیس خارج از محدوده آرایه) و خطاهای سفارشی پرتاب‌شده توسط برنامه، بدون کرش کردن مفسر در بلوک catch مهار می‌شوند:

exceptions.persi
try {
    int denom = 0;
    if denom == 0 {
        throw class="token-str">"خطا: تقسیم بر صفر مجاز نیست!";
    }
} catch (error_msg) {
    print(class="token-str">"خطا مهار شد:", error_msg);
}
Output:
خطا مهار شد: خطا: تقسیم بر صفر مجاز نیست!

۷. کتابخانه استاندارد خودمیزبان و Prelude

ساختارهای پشته (Stack)، صف (Queue)، مجموعه (Set) و بافر رشته (StringBuilder) همیشه به صورت پیش‌درآمد در تمام برنامه‌ها بدون نیاز به ایمپورت در دسترس هستند:

prelude.persi
Stack stack = Stack();
stack.push(class="token-str">"آیتم اول");
stack.push(class="token-str">"آیتم دوم");
print(class="token-str">"خارج شده از پشته:", stack.pop());
from std.math import sqrt;
print(class="token-str">"جذر عدد 64 برابر است با:", sqrt(64.0));
Output:
خارج شده از پشته: آیتم دوم
جذر عدد 64 برابر است با: 8
