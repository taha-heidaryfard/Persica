Classes & Structs (OOP)

Learn Persica’s dual object model: pure-data value structs vs. reference-based object classes with methods and state.

The Dual Object Philosophy

Persica solves one of the oldest debates in language design by providing two distinct, purpose-built constructs:

struct (Pure Data)

Used for lightweight models: coordinates, dimensions, RGB colors, points.

  • Value Semantics: Copied when passed or assigned.
  • No Methods: Pure state without behavior.
  • Equality: Deep structural comparison.

class (State & Behavior)

Used for active entities: bank accounts, database clients, network sockets.

  • Reference Semantics: Shared reference when assigned.
  • Has Methods: Full access to internal state via this.
  • Identity: Mutating one reference affects all shared holders.

Pure Value Structs (`struct`)

Define a struct by naming its fields. Instances are instantiated by calling the struct name like a function:

struct_demo.persi
struct Point {
    int x;
    int y;
}
Point p1 = Point(10, 20);
print(class="token-str">"Point p1:", p1.x, p1.y);
// Copy by value: modifying p2 does NOT affect p1
Point p2 = p1;
p2.x = 99;
print(class="token-str">"p1.x after p2 change:", p1.x);
print(class="token-str">"p2.x:", p2.x);
Output:
Point p1: 10 20
p1.x after p2 change: 10
p2.x: 99

Object-Oriented Classes (`class`)

Classes encapsulate fields with optional default values and methods:

class_demo.persi
class StopWatch {
    int elapsed_seconds = 0;
    bool is_running = false;
    void start() {
        this.is_running = true;
    }
    void tick(int seconds) {
        if this.is_running {
            this.elapsed_seconds += seconds;
        }
    }
    int get_elapsed() {
        return this.elapsed_seconds;
    }
}
StopWatch timer = StopWatch();
timer.start();
timer.tick(15);
timer.tick(30);
print(class="token-str">"Elapsed time:", timer.get_elapsed(), class="token-str">"seconds");
Output:
Elapsed time: 45 seconds

Methods & The `this` Keyword

Within any method, the this keyword explicitly references the active instance. Methods can call sibling methods directly:

bank_account.persi
class Account {
    string owner;
    int balance = 0;
    void deposit(int amount) {
        this.balance += amount;
        this.log_audit(class="token-str">"Deposited " + to_string(amount));
    }
    void log_audit(string event) {
        print(class="token-str">"[AUDIT]", this.owner, class="token-str">"-", event, class="token-str">"| Balance:", this.balance);
    }
}
Account acc = Account();
acc.owner = class="token-str">"Mohammad Taha";
acc.deposit(500);
acc.deposit(250);
Output:
[AUDIT] Mohammad Taha - Deposited 500 | Balance: 500
[AUDIT] Mohammad Taha - Deposited 250 | Balance: 750

Value vs. Reference Semantics

When you assign an instance of a class to another variable, both variables point to the same underlying heap object (managed with Rust’s reference counted cell):

references.persi
class SharedState {
    int counter = 0;
}
SharedState ref1 = SharedState();
SharedState ref2 = ref1; // Shared reference
ref2.counter = 42;
// ref1 sees the change because both share the same instance!
print(class="token-str">"ref1.counter:", ref1.counter);
Output:
ref1.counter: 42

Collections of Objects

Both structs and classes can be stored within arrays and maps:

object_lists.persi
struct Task {
    int id;
    string title;
    bool done;
}
Task[] todo_list = [
    Task(1, class="token-str">"Install Persica", true),
    Task(2, class="token-str">"Learn OOP syntax", true),
    Task(3, class="token-str">"Build awesome app", false)
];
for task in todo_list {
    string status = task.done ? class="token-str">"[DONE]" : class="token-str">"[PENDING]";
    print(status, task.title);
}
Output:
[DONE] Install Persica
[DONE] Learn OOP syntax
[PENDING] Build awesome app
