Exception Handling (try / catch / throw)

Learn how Persica prevents panics and manages errors gracefully using try, catch, and throw with complete call-stack unwinding.

The Zero-Panic Guarantee

In Persica, no error in user code is allowed to crash or panic the interpreter. The language provides a comprehensive exception handling model allowing programs to intercept both custom user errors and internal runtime errors (like division by zero or array bounds violations) safely.

Basic `try` and `catch`

Wrap vulnerable code blocks inside a try block followed by a catch block:

basic_try.persi
try {
    print(class="token-str">"Executing sensitive operation...");
    throw class="token-str">"Database unreachable!";
    print(class="token-str">"This line will never be reached.");
} catch (error) {
    print(class="token-str">"Intercepted error message:", error);
}
print(class="token-str">"Application recovered smoothly! ✨");
Output:
Executing sensitive operation...
Intercepted error message: Database unreachable!
Application recovered smoothly! ✨

The `throw` Statement

You can throw any expression: descriptive error strings, numeric HTTP status codes, structured dictionaries, or custom objects:

throwing.persi
// Throwing numeric error codes
try {
    throw 404;
} catch (code) {
    print(class="token-str">"Caught HTTP Error Code:", code);
}
// Throwing structured dictionary payloads
try {
    throw {
        class="token-str">"status": 500,
        class="token-str">"detail": class="token-str">"Failed to serialize JSON payload"
    };
} catch (err_dict) {
    print(class="token-str">"Status:", err_dict[class="token-str">"status"]);
    print(class="token-str">"Detail:", err_dict[class="token-str">"detail"]);
}
Output:
Caught HTTP Error Code: 404
Status: 500
Detail: Failed to serialize JSON payload

Catch Syntax Variants

Persica’s parser supports several flexible styles for catching exceptions:

syntax_styles.persi
// 1. Standard with parentheses
try { throw class="token-str">"err1"; } catch (e) { print(e); }
// 2. Pythonic without parentheses
try { throw class="token-str">"err2"; } catch e { print(e); }
// 3. Explicit type annotation
try { throw class="token-str">"err3"; } catch (string e) { print(e); }
// 4. Anonymous catch (discard error value)
try { throw class="token-str">"err4"; } catch { print(class="token-str">"Error caught silently"); }

Trapping Built-in Runtime Errors

Built-in operational faults (e.g. division by zero, missing dictionary keys, array index out of bounds) are automatically converted into catchable exceptions:

trapping.persi
// Trapping division by zero
try {
    int a = 10;
    int b = 0;
    int c = a / b;
} catch (err) {
    print(class="token-str">"Trapped arithmetic error:", err);
}
// Trapping array bounds violation
try {
    int[] list = [1, 2, 3];
    int invalid = list[99];
} catch (err) {
    print(class="token-str">"Trapped bounds error:", err);
}
Output:
Trapped arithmetic error: runtime error: division by zero
Trapped bounds error: runtime error: array index out of bounds: index 99 but length is 3

Call-Stack Unwinding

When an exception occurs deep inside nested function calls, Persica cleanly unwinds the call stack and releases scoped memory until it reaches an active enclosing try block:

stack_unwinding.persi
void level3() {
    print(class="token-str">"In level 3: about to throw");
    throw class="token-str">"Fatal failure in level 3!";
    print(class="token-str">"Unreachable");
}
void level2() {
    print(class="token-str">"In level 2");
    level3();
}
void level1() {
    print(class="token-str">"In level 1");
    level2();
}
try {
    level1();
} catch (failure) {
    print(class="token-str">"Caught at top-level:", failure);
}
Output:
In level 1
In level 2
In level 3: about to throw
Caught at top-level: Fatal failure in level 3!

Re-throwing Exceptions

Catch blocks can log or audit an error, and then re-throw it to outer layers:

rethrow.persi
try {
    try {
        throw class="token-str">"Initial trigger";
    } catch (inner) {
        print(class="token-str">"Logged in inner handler:", inner);
        throw inner; // Re-throw to outer block
    }
} catch (outer) {
    print(class="token-str">"Handled finally in outer block:", outer);
}
Output:
Logged in inner handler: Initial trigger
Handled finally in outer block: Initial trigger
