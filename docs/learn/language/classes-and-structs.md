# ساختارها و کلاس‌ها (`struct` و `class`)

زبان پرسیکا از نسخه‌ی 0.9 دو مفهوم کلیدی برای مدل‌سازی موجودیت‌ها معرفی کرده است:

1. **`struct`**: مدل داده‌ای خالص (Pure Data Model) با رفتار کپی مقداری (Value Semantics).
2. **`class`**: مدل شیء و رفتار (Object Model) با رفتار ارجاعی (Reference Semantics) و پشتیبانی از متدها.

---

## ۱. ساختار (`struct` — مدل داده‌ای)

برای گروه‌بندی داده‌های مرتبط مانند مختصات، ابعاد، رنگ‌ها یا رکوردهای داده‌ای بدون متد استفاده می‌شود:

```persica
struct Point {
    int x;
    int y;
}

// مقداردهی با constructor موقعیتی:
Point p1 = Point(10, 20);
print(p1.x, p1.y); // 10 20

// تغییر فیلد:
p1.x = 42;
print(p1.x); // 42
```

### سمانتیک مقداری (Value Semantics):
تخصیص ساختار به یک متغیر جدید، یک نسخه‌ی کپی مستقل می‌سازد:

```persica
Point p2 = p1;
p2.x = 99;

print(p1.x); // 42 (دست‌نخورده باقی می‌ماند!)
print(p2.x); // 99
```

> **نکته**: ساختارها نمی‌توانند شامل متد (`def`) باشند. در صورت نیاز به رفتار، باید از `class` استفاده شود.

---

## ۲. کلاس (`class` — مدل شیء و رفتار)

برای تعریف موجودیت‌هایی که وضعیت (فیلدها) و رفتار (متدها) دارند مانند کاربر، حساب بانکی یا فایل استفاده می‌شود:

```persica
class User {
    string name;
    int age;

    // تعریف متد با بازگشت ضمنی void یا صریح
    def introduce() {
        print("سلام! من " + name + " هستم.");
    }

    def void birthday() {
        this.age = this.age + 1;
    }

    def int get_age() {
        return age;
    }
}
```

### استفاده و سمانتیک ارجاعی (Reference Semantics):
```persica
User u1 = User("طاها", 22);
u1.introduce(); // سلام! من طاها هستم.

// در کلاس‌ها، متغیرها ارجاع به یک شیء مشترک هستند:
User u2 = u1;
u2.birthday();

print(u1.get_age()); // 23 (سن هر دو ارجاع تغییر کرد!)
```

---

## ۳. متدها و کلمه‌ی کلیدی `this`

- در داخل متدهای کلاس، فیلدها هم به‌صورت مستقیم (`name`) و هم از طریق `this.name` در دسترس هستند.
- متدها می‌توانند سایر متدهای همان کلاس را فراخوانی کنند (`this.introduce()` یا `introduce()`).
- استفاده از `this` بیرون از متدهای کلاس غیرمجاز است و خطای زمان کامپایل تولید می‌کند.

---

## ۴. کاربرد در آرایه‌ها و مپ‌ها

ساختارها و کلاس‌ها می‌توانند در آرایه‌ها و مپ‌ها استفاده شوند:

```persica
Point[] coordinates = [Point(0, 0), Point(10, 20)];
coordinates[0].x = 5;

User[] team = [User("طاها", 22), User("سارا", 20)];
team[0].introduce();

map<string, Point> landmarks = {
    "tehran": Point(35, 51),
    "shiraz": Point(29, 52)
};
```
