# مدیریت خطا و استثناها (Exceptions: `try / catch / throw`)

در نسخه **0.12.0** زبان پرسیان، سیستم قدرتمند مدیریت خطا و استثناها به سبک زبان‌های مدرن پیاده‌سازی شده است. این سیستم به برنامه‌نویس اجازه می‌دهد بدون توقف یا کرش ناگهانی برنامه، خطاها را مهار کرده و سناریوهای بازگشتی (Fallback) مناسب را اجرا نماید.

---

## ۱. ساختار پایه `try / catch`

هر کدی که احتمال بروز خطا دارد درون بلوک `try` قرار می‌گیرد. در صورت بروز خطا، اجرای کد فوراً متوقف شده و به بلوک `catch` منتقل می‌شود:

```persica
try {
    print("شروع پردازش...");
    throw "دسترسی غیرمجاز!";
    print("این خط هرگز اجرا نمی‌شود");
} catch (error) {
    print("خطا مهار شد:", error);
}
print("ادامه برنامه...");
```

---

## ۲. سینتکس‌های مختلف `catch`

زبان پرسیان آزادی عمل کامل در نحوه نوشتن بلوک `catch` به شما می‌دهد:

1. **سبک استاندارد با پرانتز:**
   ```persica
   try { ... } catch (error) { ... }
   ```
2. **سبک تمیز بدون پرانتز:**
   ```persica
   try { ... } catch error { ... }
   ```
3. **با نوع مشخص (`string`, `int`, ...):**
   ```persica
   try { ... } catch (string error) { ... }
   ```
4. **بلوک ناشناس (بدون نیاز به نام متغیر):**
   ```persica
   try { ... } catch {
       print("خطایی رخ داد!");
   }
   ```

---

## ۳. پرتاب هر نوع داده با `throw`

شما محدود به پرتاب متن نیستید؛ می‌توانید هر نوع مقداری را به عنوان خطا ارسال کنید:

```persica
// پرتاب کد خطای عددی
try {
    throw 404;
} catch (code) {
    print("HTTP Code:", code);
}

// پرتاب آبجکت دیکشنری حاوی جزئیات خطا
try {
    throw {
        "code": 500,
        "service": "AuthService",
        "message": "Token expired"
    };
} catch (err_obj) {
    print("Service:", err_obj["service"]);
    print("Message:", err_obj["message"]);
}
```

---

## ۴. مهار خطاهای خودکار مفسر (Builtin Runtime Errors)

تمامی خطاهای داخلی سیستم رانتایم پرسیان به جای کرش دادن برنامه، توسط بلوک `try / catch` قابل دریافت و مدیریت هستند:

### الف) تقسیم بر صفر
```persica
int zero = 0;
try {
    int res = 100 / zero;
} catch (e) {
    print("تقسیم بر صفر رخ داد:", e);
}
```

### ب) ایندکس نامعتبر آرایه (Out of Bounds)
```persica
int[] arr = [10, 20];
try {
    print(arr[99]);
} catch (e) {
    print("خطای اندیس آرایه:", e);
}
```

### ج) کلید ناموجود در دیکشنری
```persica
dict user = {"name": "Persica"};
try {
    print(user["email"]);
} catch (e) {
    print("کلید یافت نشد:", e);
}
```

## ۵. بازگشت پشته فراخوانی توابع (Call-Stack Unwinding)

اگر خطایی در عمق توابع رخ دهد، پشته فراخوانی به صورت خودکار باز شده و تمام متغیرهای محلی تمیز می‌شوند تا به اولین بلوک `try / catch` دربرگیرنده برسد:

```persica
def void level3() {
    throw "خطا در عمیق‌ترین سطح!";
}

def void level2() {
    level3();
}

def void level1() {
    level2();
}

try {
    level1();
} catch (e) {
    print("خطا در main مهار شد:", e);
}
```

---

## ۶. مقادیر بازگشتی توابع و `throw`

اگر تابعی باید مقداری برگرداند، دستور `throw` به عنوان یک مسیر پایانی معتبر شناخته می‌شود و نیازی به `return` ساختگی پس از آن نیست:

```persica
def int calculate(int x) {
    if (x >= 0) {
        return x * 10;
    }
    throw "عدد نمی‌تواند منفی باشد";
}
```
