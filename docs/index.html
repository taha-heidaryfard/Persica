🌿 Persica Programming Language

A lightweight, statically-typed, and developer-friendly programming language built completely from scratch in Rust. Persica combines the ergonomics and syntactic beauty of Python with the safety, predictability, and performance of typed systems.

Version 0.13.0 Zero Dependencies 138 Passing Tests MIT License

⚡ Zero Ceremony

Run individual scripts instantly like Python without project scaffolding: persica script.persi

🔒 Isolated .persi_env

Lightweight isolated package environment without duplicating heavy binary executables.

🛡️ Robust Exceptions

Modern try / catch / throw handling with call-stack unwinding and zero Rust panics.

📥 Installation

The easiest way to install Persica on Windows is through the official setup installer:

Download Windows Setup: Download Persica-0.13.0-Windows-x64-Setup.exe from the GitHub Releases. It automatically configures persica in your system PATH.

Or build directly from source using Cargo:

Terminal 
git clone https://github.com/taha-heidaryfard/Persica.git
cd Persica
cargo build --release

⚡ First Program

Create a file named app.persi:

app.persi 
print("Greetings from Persica! 🌿");

int total = 0;
for i in range(1, 6) {
    total += i;
    print("Step:", i, "Total:", total);
}

Run it directly:

Terminal 
persica app.persi

📁 Project System & persica.toml

Scaffold multi-file projects with one command:

Terminal 
persica new my_application
cd my_application
persica run

The generated persica.toml manages your package config:

persica.toml 
[package]
name = "my_application"
version = "0.1.0"
entry = "src/main.persi"
source = "src"

[environment]
env_dir = ".persi_env"

🏛️ Classes & Structs

Persica distinguishes pure value structs from reference-based object classes:

oop.persi 
// Value-semantics pure data structure
struct Point {
    int x;
    int y;
}

// Object with internal state and behavior
class BankAccount {
    string owner;
    int balance = 0;

    void deposit(int amount) {
        this.balance += amount;
    }

    int get_balance() {
        return this.balance;
    }
}

BankAccount acc = BankAccount();
acc.deposit(500);
print("Account balance:", acc.get_balance());

🛡️ Exception Handling (try / catch / throw)

exceptions.persi 
try {
    int num = 10;
    int denom = 0;
    if denom == 0 {
        throw "Error: division by zero!";
    }
} catch (err) {
    print("Successfully handled exception:", err);
}

📚 Self-Hosted Standard Library

Classic structures (Stack, Queue, Set, StringBuilder) are built directly in Persica and available out of the box:

stdlib.persi 
// Auto-Prelude Stack
Stack s = Stack();
s.push(100);
s.push(200);
print("Popped item:", s.pop());

// Importing standard math
from std.math import sqrt;
print("Square root of 25 is:", sqrt(25.0));

Persica provides a rich VS Code extension with syntax highlighting, live type checking on save, auto-complete, and one-click execution:

Terminal

🛠️ CLI Command Reference

Commands 
persica <file.persi>              Run a standalone single script
persica new <project_name>        Scaffold a new project with .persi_env
persica run                       Run project entry defined in persica.toml
persica test                      Execute unit tests in tests/ directory
persica check <file.persi>        Static semantic validation without execution
persica --eval "print(1 + 2);"    Evaluate inline Persica code directly
