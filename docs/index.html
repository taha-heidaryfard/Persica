🌿 زبان برنامه‌نویسی پرسیکا (Persica)

یک زبان برنامه‌نویسی مدرن، ایستا-نوع (Statically-Typed) و مستقل که از صفر با زبان Rust پیاده‌سازی شده است. پرسیکا ظرافت و راحتی سینتکس پایتون را با ایمنی و قابلیت اطمینان سیستم‌های تایپ‌شده ترکیب می‌کند.

نسخه 0.13.0 Zero Dependencies 138 تست پاس‌شده مجوز متن‌باز MIT

⚡ اجرای بدون تشریفات

امکان اجرای مستقیم فایل‌های تکی بدون نیاز به ساخت فایل پروژه: persica script.persi

🔒 محیط ایزوله .persi_env

ایزولاسیون کامل پکیج‌ها بدون نیاز به تکثیر فایل‌های اجرایی سنگین مفسر.

🛡️ مدیریت کامل استثنا

سیستم مدرن try / catch / throw با Unwinding کامل پشته فراخوانی و بدون کوچک‌ترین Panic در رانتایم.

📥 نصب و راه‌اندازی

ساده‌ترین راه برای نصب در ویندوز، استفاده از فایل نصاب رسمی است:

دانلود نصاب ویندوز: فایل Persica-0.13.0-Windows-x64-Setup.exe را از بخش Releases گیت‌هاب دانلود کرده و اجرا کنید. این نصاب به طور خودکار دستور persica را در ترمینال شما ست می‌کند.

همچنین می‌توانید سورس پروژه را با Rust کامپایل کنید:

Terminal 
git clone https://github.com/taha-heidaryfard/persica.git
cd persica
cargo build --release

⚡ اولین برنامه شما

یک فایل با نام app.persi بسازید:

app.persi 
print("درود بر پرسیکا! 🌿");

int total = 0;
for i in range(1, 6) {
    total += i;
    print("مرحله:", i, "مجموع:", total);
}

و آن را مستقیماً اجرا کنید:

Terminal 
persica app.persi

📁 سیستم مدیریت پروژه و persica.toml

برای پروژه‌های چندفایله و بزرگ، می‌توانید با یک دستور پروژه بسازید:

Terminal 
persica new my_application
cd my_application
persica run

فایل persica.toml ایجاد شده شامل تنظیمات سبک و شفاف پکیج است:

persica.toml 
[package]
name = "my_application"
version = "0.1.0"
entry = "src/main.persi"
source = "src"

[environment]
env_dir = ".persi_env"

🏛️ کلاس‌ها و استراکت‌ها

پرسیکا تفکیک مشخصی میان ساختار داده‌ای خالص (Value Semantics) و اشیاء دارای رفتار (Reference Semantics) دارد:

oop.persi 
// مدل داده‌ای خالص بدون متد
struct Point {
    int x;
    int y;
}

// شیء دارای رفتار، متدها و وضعیت داخلی
class BankAccount {
    string owner;
    int balance = 0;

    void deposit(int amount) {
        this.balance += amount;
    }

    int get_balance() {
        return this.balance;
    }
}

BankAccount acc = BankAccount();
acc.deposit(500);
print("موجودی حساب:", acc.get_balance());

🛡️ سیستم مدیریت استثنا (try / catch / throw)

exceptions.persi 
try {
    int num = 10;
    int denom = 0;
    if denom == 0 {
        throw "خطا: تقسیم بر صفر مجاز نیست!";
    }
} catch (err) {
    print("استثنا با موفقیت مهار شد:", err);
}

📚 کتابخانه استاندارد خودمیزبان

کلاس‌های پایه‌ای نظیر پشته، صف، مجموعه و الگوریتم‌های مرتب‌سازی به صورت خودکار بدون نیاز به ایمپورت در دسترس هستند:

stdlib.persi 
// استفاده مستقیم از Prelude
Stack s = Stack();
s.push(100);
s.push(200);
print("آیتم خارج شده:", s.pop());

// ایمپورت ماژول‌های ریاضی یا رشته
from std.math import sqrt;
print("جذر 25 برابر است با:", sqrt(25.0));

🛠️ دستورات خط فرمان (CLI Reference)

Commands 
persica <file.persi>              اجرای مستقیم یک اسکریپت تکی
persica new <project_name>        ساخت پروژه جدید
persica run                       اجرای پروژه فعلی بر اساس persica.toml
persica test                      اجرای تمام تست‌های پوشه tests
persica check <file.persi>        اعتبارسنجی استاتیک کد بدون اجرا
persica --eval "print(1 + 2);"    اجرای فوری قطعه کد به صورت خطی
