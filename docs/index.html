The ergonomics of Python, the safety of Rust.

Persica is a lightweight, statically-typed, and zero-dependency programming language crafted from scratch in Rust. Featuring a dedicated project system, isolated .persi_env, object-oriented classes, robust exceptions, and a 1-click Windows installer.

// Zero ceremony: run directly like Python!
print(class="token-str">"Greetings from Persica! 🌿");
int sum = 0;
for num in range(1, 6) {
    sum += num;
    print(class="token-str">"Step:", num, class="token-str">"Accumulated:", sum);
}
print(class="token-str">"Final total:", sum);

Engineered for Simplicity & Power

Every detail is designed to give you a modern, joy-filled coding experience.

Zero Ceremony Execution

Run standalone scripts directly like Python without creating a project or compiling scaffolding. Just persica script.persi.

Isolated .persi_env

Package environment system inspired by Python’s venv, but ultra-lightweight: zero binary duplication of the executable interpreter.

Zero Rust Panics Guarantee

User code errors will NEVER cause a Rust panic. Full try / catch / throw handling with call-stack unwinding.

Classes & Structs

Clear distinction: value-semantics pure data structs (struct) and reference-semantics object classes (class).

Self-Hosted Prelude & Stdlib

Dogfooding 100%: standard library and prelude (Stack, Queue, Set, StringBuilder, Result, Option) written directly in Persica.

Official VS Code Extension

Rich editor extension with syntax highlighting, live type-check diagnostics on save, IntelliSense auto-complete, hover docs, and 1-click run buttons.
