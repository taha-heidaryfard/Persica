# Persica 0.1.0

## هدف نسخه

نسخه‌ی 0.1 اولین بازنویسی مستقل Persica از Java به Rust بود. هدف آن ساخت pipeline صحیح و تست‌پذیر برای هسته‌ی expression language بود، نه گسترش سریع featureها.

## قابلیت‌های زبان

- نوع‌های `int`، `bool` و `string`
- تعریف و assignment متغیر
- expression arithmetic و comparison
- logical operator با short-circuit
- unary operator و grouping
- `print`
- اتصال دو رشته با `+`
- line و nested block comment
- identifierهای Unicode

## اجزای compiler

- lexer با span دقیق
- recursive-descent parser
- enum-based AST
- semantic type/name validation
- tree-walk interpreter
- source-aware diagnostics

## Tooling

- اجرای فایل یا `main.persi`
- `--tokens`
- `--ast`
- library API شامل `compile` و `run`

## تصمیم‌های مهم

- `int` به `i64` محدود شد.
- نوع declaration در AST حفظ شد؛ برخلاف نسخه‌ی Java دور ریخته نمی‌شود.
- خروجی interpreter جمع‌آوری می‌شود تا testable باشد.
- dependency خارجی استفاده نشد.

## تفاوت با نسخه‌ی Java

- string واقعاً parse و اجرا شد.
- number دیگر string runtime نیست.
- undefined variable و mismatch نوع پیش از اجرا تشخیص داده شدند.
- `&&` و `||` short-circuit شدند.
- build، CLI و test suite قابل اتکا شدند.

## تست و پذیرش

نسخه با unit test lexer و integration testهای expression، typing، assignment، Unicode، diagnostics، overflow و division by zero تحویل شد.

## محدودیت‌ها

block، condition، loop، function، array، input و module در این نسخه وجود نداشتند.
