# Persica 0.6.0

این نسخه سینتکس اصلی Persica را به ترکیبی از declarationهای صریح Java و جریان ساده‌ی Python نزدیک می‌کند، بدون شکستن قابلیت‌های 0.5.

## سینتکس نهایی اضافه‌شده

```persica
int x = to_int(input());

for i in range(x) {
    print(i);
}

string name = "ali";
final int limit = 10;
```

## ورودی و خروجی

- `input()` یک خط می‌خواند.
- `input("Prompt: ")` پیش از خواندن prompt را بدون newline نمایش می‌دهد.
- `print()` newline خالی می‌نویسد.
- `print(a, b)` مقدارها را با فاصله جدا می‌کند.
- `print(a, b, sep=", ", end="!")` جداکننده و پایان را دقیق کنترل می‌کند.
- `read_line()` برای سازگاری کد قدیمی باقی مانده است.

## حلقه و range

- `for name in array` روی اعضای آرایه حرکت می‌کند.
- `for name in string` روی نویسه‌های Unicode حرکت می‌کند.
- `range(end)` از صفر شروع می‌شود.
- `range(start, end)` بازه‌ی نیمه‌باز می‌سازد.
- `range(start, end, step)` گام مثبت یا منفی می‌پذیرد؛ گام صفر خطای runtime است.
- حلقه‌ی C-style نسخه‌ی 0.5 همچنان پشتیبانی می‌شود.

## final

`final` اتصال متغیر را ثابت می‌کند. assignment ساده، مرکب و increment/decrement روی آن semantic error است. در آرایه‌ی final، جایگزینی کل آرایه ممنوع ولی تغییر عضو مجاز است.

## شرط‌ها

هر دو شکل `if condition {}` و `if (condition) {}` معتبرند. همین قانون برای `while` اعمال می‌شود.

## API runtime

- `Interpreter::interpret` خروجی منطقی هر print را برای سازگاری برمی‌گرداند.
- `Interpreter::interpret_text` متن دقیق خروجی را برمی‌گرداند.
- `Interpreter::with_stdio` input و output تعاملی با flush prompt را فراهم می‌کند.

## تست و سازگاری

فایل `tests/version_06.rs` حالت‌های موفق و خطا را پوشش می‌دهد. مجموعه‌های v0.1، v0.5 و CLI بدون تغییر رفتار قبلی عبور می‌کنند.
