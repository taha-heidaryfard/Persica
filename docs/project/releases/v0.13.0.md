# Persica v0.13.0 Release Notes

**تاریخ انتشار:** 2026-10-29  
**نسخه:** `0.13.0`  
**وضعیت:** Stable

---

## چکیده تغییرات

در نسخه 0.13.0، پرسیکا به سیستم رسمی مدیریت پروژه، فایل پیکربندی `persica.toml` و محیط ایزوله پکیج‌های محلی `.persi_env` مجهز شد. همچنین اجرای تک‌فایل مستقل بدون تشریفات پروژه به سبک پایتون کاملاً پشتیبانی می‌شود.

---

## قابلیت‌های کلیدی

### ۱. اجرای بدون تشریفات فایل تکی (Zero-Ceremony Single File)
کاربران برای تست یا اجرای کدهای سبک، نیازی به ساخت ساختار پروژه ندارند:
```bash
persica script.persi
```

### ۲. سیستم مدیریت پروژه و پیکربندی `persica.toml`
پروژه‌های پرسیکا می‌توانند با یک فایل سبک `persica.toml` پیکربندی شوند:
```toml
[package]
name = "my_app"
version = "0.1.0"
entry = "src/main.persi"
source = "src"

[environment]
env_dir = ".persi_env"
```

### ۳. فراخوانی فایل کانفیگ و نقطه ورود دلخواه
امکان اجرای مستقیم پروژه از طریق کانفیگ:
```bash
# اجرای خودکار فایل entry تعیین شده در کانفیگ:
persica persica.toml

# اجرای یک فایل معین با لود کردن تنظیمات و مسیرهای پروژه:
persica persica.toml src/main.persi
```

### ۴. محیط ایزوله ماژول‌ها و بسته‌ها (`.persi_env`)
مشابه با `.venv` در پایتون، بدون تکثیر باینری سنگین مفسر (`persica.exe`):
- مسیر ایمپورت‌ها اولویت‌بندی شده است:
  1. مسیر نسبی فایل جاری (`./`)
  2. مسیر پوشه کدهای پروژه (`src/`)
  3. محیط ماژول‌های ایزوله محلی (`.persi_env/`)
  4. کتابخانه استاندارد توکار (`std/`)

### ۵. دستورات جدید خط فرمان (CLI Tooling)
- `persica new <name>`: ایجاد پروژه کامل به همراه فایل `persica.toml`، پوشه `src/`، محیط `.persi_env/` و فایل `src/main.persi`.
- `persica init`: مقداردهی اولیه پوشه فعلی به عنوان پروژه پرسیکا.
- `persica run`: اجرای فایل اصلی پروژه بر اساس `persica.toml` موجود در مسیر.
- `persica test`: اجرای خودکار تمام تست‌های موجود در پوشه `tests/`.
- `persica check`: اعتبارسنجی سینتکسی و استاتیکی کدها بدون اجرا.
