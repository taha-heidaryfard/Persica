# Persica 0.5.0

## هدف نسخه

تبدیل هسته‌ی 0.1 به یک زبان اسکریپتی تایپ‌شده و قابل استفاده برای برنامه‌های الگوریتمی، تعاملی و چندتابعی.

## قابلیت‌های جدید زبان

### Scope و کنترل جریان

- block و lexical scope
- shadowing
- `if / else`
- `while` و C-style `for`
- `break` و `continue`

### توابع

- `def` با پارامتر و return type
- `void`
- `return`
- forward call
- recursion و mutual recursion
- validation مسیر return
- محدودیت ۲۵۶ call frame

### آرایه‌ها

- `T[]` و آرایه‌ی چندبعدی
- literal و array خالی context-aware
- indexing و nested mutation
- deep equality
- bounds diagnostics

### عملگرها

- `%`
- `+= -= *= /= %=`
- `++ --`
- compound assignment روی array index

### Built-inها

- `len`
- `range`
- `append`
- `to_string`
- `to_int`
- `read_line`

## تغییرات compiler

- AST برای statementهای control flow، function و array گسترش یافت.
- semantic analyzer دارای scope stack، function signature pre-pass و control-flow context شد.
- expected type برای array خالی اضافه شد.
- reserved built-in validation اضافه شد.

## تغییرات runtime

- scope stack و function call frame
- مدل داخلی `Flow` برای break/continue/return
- mutation آرایه‌ی تودرتو
- ورودی disabled، injected و stdin
- محافظت recursion، range، bounds و arithmetic

## تغییرات CLI

- `--check`
- `--eval`
- `--version`
- source از stdin با `-`
- stdout/stderr و exit code تست‌شده

## سازگاری

برنامه‌های معتبر 0.1 همچنان اجرا می‌شوند. suite مستقل compatibility حفظ شده است. keywordهای جدید مانند `if`، `def` و `for` دیگر نمی‌توانند نام identifier باشند؛ این تنها ناسازگاری source بالقوه است.

## تست و پذیرش

- unit test lexer
- compatibility suite نسخه‌ی 0.1
- feature suite نسخه‌ی 0.5
- تست واقعی binary برای eval، check، diagnostics، stdin و read_line
- fmt، clippy با warning-as-error، test و release build موفق

## محدودیت‌ها

- module/import وجود ندارد.
- REPL ماندگار وجود ندارد.
- file I/O و network standard library وجود ندارد.
- تابع first-class و closure وجود ندارد.
- runtime هنوز tree-walk و single-threaded است.
