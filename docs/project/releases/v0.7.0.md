# Persica 0.7.0

این نسخه بدون افزودن فایل، module، error handling، REPL یا ابزار ادیتور، توان پردازش داده داخل حافظه را گسترش می‌دهد.

## float

- type و literal جدید `float` مانند `12.5`
- arithmetic، modulo، comparison، negation و equality
- آرایه، پارامتر و خروجی تابع از نوع float
- `to_float(string | int | float)`
- `to_int` برای float متناهی و بدون بخش کسری
- نبود تبدیل ضمنی بین int و float

## متن

توابع `upper`، `lower`، `trim`، `trim_start`، `trim_end`، `contains`، `starts_with`، `ends_with`، `replace`، `split`، `join`، `repeat`، `find`، `count`، `slice` و `reverse` اضافه شدند. indexهای متن برحسب نویسه‌ی Unicode هستند.

## عدد

توابع `abs`، `min`، `max`، `clamp`، `pow`، `sqrt`، `round`، `floor` و `ceil` اضافه شدند. عملیات نامعتبر به‌جای panic diagnostic کنترل‌شده می‌دهند.

## آرایه

توابع `contains`، `slice`، `reverse`، `sort`، `sum`، `insert` و `remove` اضافه شدند. همه non-mutating هستند و مقدار جدید می‌سازند. index منفی برای slice/remove/insert پشتیبانی می‌شود.

## محدودیت‌ها

- literal علمی مانند `1e3` هنوز وجود ندارد.
- تبدیل عددی ضمنی وجود ندارد.
- `sum` آرایه‌ی خالی را رد می‌کند.
- `sort` فقط آرایه‌های int، float و string را می‌پذیرد.
- `repeat` برای جلوگیری از مصرف کنترل‌نشده‌ی حافظه محدود است.

## اعتبارسنجی

مجموعه‌ی `tests/version_07.rs` مسیرهای موفق، type error، Unicode، index منفی، overflow و خطاهای وابسته به مقدار را پوشش می‌دهد. تست‌های نسخه‌های 0.1، 0.5 و 0.6 نیز حفظ شده‌اند.
