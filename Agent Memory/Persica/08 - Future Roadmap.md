# 08 - Future Roadmap 🚀

نقشه راه و اهداف توسعه زبان Persica در فازهای آینده.

---

## 🎯 فازهای آتی به ترتیب اولویت

### ۱. سیستم ماژولار و وارد کردن فایل‌ها (`import` / `module`)
امکان تقسیم پروژه‌های بزرگ به چند فایل و اشتراک‌گذاری توابع، کلاس‌ها و ساختارها:
```persica
import "utils.persi";
// یا
import { User, Point } from "models.persi";
```

### ۲. خودمیزبانی توابع استاندارد (Persica Prelude)
نوشتن توابع سطح بالای استاندارد با خود زبان Persica در فایلی نظیر `src/stdlib/prelude.persi` و بارگذاری اولیه آن با `include_str!` توسط مفسر.

### ۳. موتور بایت‌کد و ماشین مجازی (Bytecode VM)
جایگزینی مفسر درختی (Tree-walk Interpreter) با یک ماشین مجازی مبتنی بر پشته (Stack-based Virtual Machine) جهت افزایش ۱۰ تا ۵۰ برابری سرعت اجرای کدهای پرسیکا.

### ۴. پکیج منیجر و ابزار CLI توسعه
ساخت ابزاری شبیه `cargo` یا `npm` برای مدیریت پکیج‌ها و ایجاد پروژه‌های جدید در پرسیکا (`persica new`, `persica run`, `persica test`).

## ✅ فازهای تکمیل‌شده
- **v0.9.0**: اضافه شدن کامل `struct` (مدل داده‌ای با سمانتیک مقداری) و `class` (مدل شیء و رفتار با سمانتیک ارجاعی، متدها و `this`).
- **v0.8.0**: اضافه شدن `map<K, V>` و `dict` با عملگرهای ایندکس و متدهای کلید/مقدار.
- **v0.7.2**: سیستم رجیستری توابع داخلی با ۱۱۵ تابع استاندارد.
