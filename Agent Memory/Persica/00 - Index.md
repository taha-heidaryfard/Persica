# Persica Agent Memory & Knowledge Base 🧠

خوش‌آمدید! این مخزن دانش (Obsidian Vault) حافظه دائمی و سیستم راهنمای هوش مصنوعی و توسعه‌دهندگان زبان برنامه‌نویسی **Persica** است. با مطالعه این مستندات، بدون نیاز به آنالیز مجدد کل سورس‌کد، در کمترین زمان ممکن بر کل معماری، فایل‌ها، منطق اجرایی و قوانین پروژه مسلط می‌شوید.

---

## 🗺️ نقشه محتوا (Map of Content)

1. [[01 - Architecture & Pipeline]]: خط لوله اجرای زبان (Lexer -> Parser -> AST -> Semantic -> Runtime)
2. [[02 - File Catalog]]: شناسنامه و مسئولیت تک‌تک فایل‌های سورس، تست‌ها و نمونه‌ها
3. [[03 - Language Syntax & Type System]]: سینتکس کامل زبان، انواع داده (`int`, `float`, `string`, `bool`, `any`, `map`, `dict`)
4. [[04 - Builtin Functions Catalog]]: فهرست کامل بیش از ۱۱۵ تابع داخلی رجیستری و توابع مپ و آرایه
5. [[05 - Invariants & Agent Rules]]: قواعد حیاتی و خط قرمزهای توسعه (بدون Panic، تست‌های رگرسیون، گیت)
6. [[06 - Verification & Testing]]: دستورات اعتبارسنجی اجباری (`fmt`, `clippy`, `test`) و ماتریس تست‌ها
7. [[07 - Version History]]: تاریخچه و تغییرات نسخه‌های مختلف تا نسخه 0.8
8. [[08 - Future Roadmap]]: اولویت‌ها و گام‌های آینده (Structs, Import/Modules, Bytecode VM)

## ⚡ خلاصه وضعیت پروژه (Snapshot)

- **زبان پیاده‌سازی:** Rust (بدون هیچ وابستگی خارجی - Zero Dependencies)
- **نسخه فعلی زبان:** `0.11.0` (کتابخانه استاندارد خودمیزبان ۱۰۰٪ پرسیان، Auto-Prelude، ساختارهای داده Stack/Queue/Set/StringBuilder، ماژول‌های `std.*` و سازنده پیش‌فرض ۰ آرگومانی کلاس‌ها)
- **تعداد کل تست‌های خودکار:** ۱۱۴ تست در ۱۲ سوئیت تستی (تماماً پاس)
- **کتابخانه استاندارد:** رجیستری یکپارچه با ۱۱۵ تابع ریاضی، رشته، آرایه، آمار + توابع اختصاصی دیکشنری
- **کنترل نسخه:** گیت فعال با شاخه `main` و کامیت‌های تمیز و استاندارد
