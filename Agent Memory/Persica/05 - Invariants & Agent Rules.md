# 05 - Invariants & Agent Rules ⚠️

این فایل شامل **قواعد تخطی‌ناپذیر** توسعه در مخزن Persica است. تمام ایجنت‌ها و برنامه‌نویسان باید این اصول را رعایت کنند.

---

## 🚫 قوانین اجباری (Non-Negotiable Rules)

1. **خطای برنامه‌ی کاربر نباید Rust panic ایجاد کند:**
   هیچ خطای کدنویسی کاربر (مانند تقسیم بر صفر، خروج از محدوده ایندکس، عدم تطابق نوع، سرریز در فاکتوریل یا کلید ناموجود مپ) نباید باعث کرش یا `panic!` مفسر شود. همه باید از طریق `Diagnostic` گزارش شوند.

2. **هماهنگی تمام لایه‌ها در تغییر زبان (Full Synchronization):**
   هر قابلیت یا سینتکس جدید زبان باید به طور همزمان و سازگار در این بخش‌ها پیاده شود:
   - `src/lexer/token.rs` و `src/lexer/mod.rs` (در صورت نیاز به توکن جدید)
   - `src/ast.rs` (تعریف ساختارهای گره‌های AST)
   - `src/parser/` (پارس کردن گرامر)
   - `src/semantic/` (بررسی نوع و اسکوپ)
   - `src/runtime/` (ارزیابی زمان اجرا)
   - `tests/` (تست‌های رفتاری مثبت و منفی)

3. **آزمون‌های الزامی (Test-Driven Delivery):**
   - هر باگ فیکس نیاز به یک **Regression Test** دارد تا باگ دوباره تکرار نشود.
   - هر Feature جدید حداقل نیاز به چندین تست مثبت (عملکرد درست) و تست منفی (رد شدن خطاهای نامعتبر) دارد.

4. **دستورات اعتبارسنجی پیش از تحویل:**
   قبل از هرگونه کامیت یا تحویل به کاربر، باید هر ۳ دستور زیر بدون خطا (Exit code 0) اجرا شوند:
   ```powershell
   cargo fmt --all -- --check
   cargo clippy --all-targets -- -D warnings
   cargo test --all-targets
   ```

5. **سازماندهی مستندات:**
   - آموزش و مستندات کاربر: `docs/learn/`
   - مستندات معماری داخلی کامپایلر: `docs/project/`
   - حافظه و مستندات agent: `Agent Memory/Persica/` و `AGENTS.md`

6. **حفظ تغییرات نامرتبط موجود در Workspace:**
   هیچ تغییری در فایل‌های نامربوط بدون اجازه ایجاد نمی‌شود و دایرکتوری `target/` هرگز دستی ادیت نمی‌شود.

7. **حفظ سازگاری به عقب (Backward Compatibility):**
   هیچ تغییری نباید کدهای نوشته شده با نسخه‌های قبلی را بدون دلیل موجه بشکند.
